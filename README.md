# AR · Лампа Pixar

Сторінка доповненої реальності (MindAR + A-Frame): наводиш камеру телефона на фото-маркер `marker.png`, і поверх нього з'являється анімована лампа Pixar з `lamp.glb`.

## Як опублікувати на GitHub Pages
1. Завантаж увесь вміст цієї папки в репозиторій (`index.html`, `lamp.glb`, `targets.mind`, `marker.png`, папка `libs`).
2. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, папка `/ (root)`.
3. Відкрий адресу `https://<користувач>.github.io/<репозиторій>/` на телефоні й дозволь доступ до камери (потрібен https).

## Маркер
`marker.png` — фото PIXAR. Показуй його на екрані іншого пристрою або друкуй на матовому папері, без відблисків. `targets.mind` скомпільовано саме з цього зображення: якщо змінити фото, маркер потрібно скомпілювати заново.
